## Simulazioni Geant4 basate su database con un'API Python

<!-- Upcoming with the next release: revised introduction. -->

**GEMC** è un'applicazione [Geant4](https://geant4.web.cern.ch) basata su database per simulazioni di rivelatori
e del trasporto di radiazioni. La sua API Python permette di definire configurazioni complesse di rivelatori
senza scrivere codice Geant4.

Le descrizioni dei rivelatori restano separate dall'eseguibile: le crei in Python, le memorizzi in database
ASCII o SQLite e GEMC le carica durante l'esecuzione per eseguire la simulazione Geant4.

<br/>

## Caratteristiche principali

- Definizione dei rivelatori principalmente in Python
- Anteprima della geometria ed esportazione VTK con [`pyvista`](https://pyvista.org)
- Database ASCII e SQLite
- Importazione di geometrie da file GDML e CAD
- Visualizzazione interattiva Geant4/Qt e generazione di immagini fuori schermo
- Rivelatori sensibili integrati: %%flux%%, %%dosimeter%%, %%particle_counter%% e %%gPhotonDetector%%
- Output della simulazione in ASCII, CSV, JSON e [ROOT](https://root.cern)
- Generazione di eventi dalla GUI, dalla riga di comando e da file YAML e LUND
- Supporto per campi magnetici, inclusi campi multipolari e mappe ASCII
- Un modulo Python `analyzer` per leggere e rappresentare graficamente l'output della simulazione (CSV, ROOT)
- Varianti della geometria e configurazioni dipendenti dal numero di run

L'obiettivo è aiutare gli utenti a realizzare prototipi di sistemi di rivelatori senza scrivere un'applicazione
Geant4 personalizzata, mentre i plugin C++ consentono di personalizzare la risposta dei rivelatori, i campi
magnetici, i generatori di eventi e i formati di output.

## `pygemc`: l'API Python

L'API Python di GEMC, `pygemc`, offre strumenti per creare database di geometrie e materiali, visualizzare
la geometria con `pyvista` e usare `gemc-system-template` e `gemc-analyzer`. Il modulo di analisi può leggere
l'output GEMC in formato CSV e ROOT e tracciare istogrammi delle variabili selezionate.

{% include figure.html
src="/assets/images/gemc_showcase.gif"
alt="Python API example"
caption="  
The code fills the database with the world volume, a liquid hydrogen target, and a flux plane. <br/>
The `pyvista` option gives immediate geometry visualization. <br/>
In the GEMC simulation, hits are created from particles generated by a beam of protons impinging
on the liquid hydrogen target.<br/>
The total deposited energy is plotted with the `analyzer` module."
%}

L'estratto seguente definisce il piano sensibile per la misura del flusso a valle del bersaglio. GEMC registra
un hit %%flux%% ogni volta che una traccia generata attraversa questo volume.

```python
# Place a thin scoring plane downstream of the target.
flux_z = 50
flux_dx = 1
flux_dim = world_size * 0.8

# Define the plane as an air box inside the world volume.
gvolume = GVolume("FluxPlane")
gvolume.mother = "root"
gvolume.description = "Flux Scoring Plane"
gvolume.make_box(flux_dim * 0.5, flux_dim * 0.5, flux_dx * 0.5)
gvolume.material = "G4_AIR"
gvolume.color = "FAFAD2"
gvolume.set_position(0, 0, flux_z)

# Turn the volume into a GEMC flux detector and tag its output column.
gvolume.digitization = "flux"
gvolume.set_identifier("flux_plane", 1)
gvolume.publish(cfg)
 ```

<br/>


> [!NOTE]
> L'esecuzione delle simulazioni non richiede alcuna conoscenza pregressa di C++ o Geant4.
> Una conoscenza di base di Python aiuta a organizzare configurazioni complesse.
> Gli utenti possono anche **definire le proprie routine di emulazione dell'hardware**. In questo caso,
> una conoscenza di base di C++ è utile per implementare digitizzazioni complesse.

## Varianti della geometria

Un rivelatore può essere riutilizzato in diversi esperimenti, modificandone la configurazione tramite
spostamenti di componenti, cambi di materiale oppure aggiunta e rimozione di volumi.
GEMC supporta queste versioni della geometria usando stringhe %%variation%% e/o numeri %%run%% per adattarsi
a diverse configurazioni di
simulazione.

src="/assets/images/clas12v.gif"
