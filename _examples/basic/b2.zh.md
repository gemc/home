## 快速开始

将示例复制到当前目录。
要创建几何结构、运行 10 个事件并生成 ROOT 和 CSV 输出文件：

```shell
cp -r $GEMC_HOME/examples/basic/b2 .
cd b2
./b2.py
gemc b2.yaml -n=10
```

<br/>

## 几何结构

如下所示的几何结构定义在 `b2.py` 中。

世界体（一个名为 %%root%% 的长方体）包含：

- %%target%%，一个由铅（%%G4_Pb%%）制成的圆柱形靶
- %%tracker%%，一个由空气（%%G4_AIR%%）制成的圆柱形容器
- 五个名为 %%chamber_0%% 到 %%chamber_4%% 的圆柱形探测室几何体，由氙（%%G4_Xe%%）制成，放置在 %%tracker%% 内部，横向尺寸依次增大

## 数字化

探测室几何体的敏感属性在 `b2.py` 中通过 %%flux%% 数字化方法（GEMC 内置例程之一）
指定。拷贝编号用于标识每个探测室：

```python
gvolume.digitization = 'flux'
gvolume.set_identifier('mychamber', copyNo)
```

在本例中，%%identifier%% 仅包含一个名称：%%mychamber%%。

更多信息请参阅 [Flux 文档]( /home/documentation/sensitivity/flux )。

除了数字化变量外，真值信息也会保存到输出流中。

{% include notes/true_info-note.md %}

## 用法

### 构建探测器

使用 Python 脚本 `b2.py` 构建探测器。默认情况下，探测器配置存储在一个名为
`gemc.db` 的 SQLite 文件中。命令行选项可以指定数据库类型、变体和运行编号。

更多信息另请参阅[构建几何结构]( /home/documentation/geometry/geometry_building )。

<br/>

### 运行 GEMC

可以使用 `b2.yaml` 文件来运行该探测器配置。添加 `-gui` 可交互式运行：

```shell
gemc b2.yaml -gui
```

根据需要修改 `b2.yaml`，特别是添加粒子、控制线程数量或更改输出。

## 输出

%%gstreamer%% 选项用于选择输出文件名和格式：

```yaml
gstreamer:
  - format: csv
    filename: b2
```

由于 %%flux%% 是逐事件的数字化方法，GEMC 将为每个线程生成一个输出文件。
对于 ROOT 文件，你可以使用 `hadd` 合并这些文件。

更多信息另请参阅[输出文档]( /home/documentation/output )。


<br/>

## 使用 GEMC 分析器绘图

首先运行 GEMC 模拟 1,000 个事件。默认的 YAML 文件会写出供分析器使用的 CSV 数据流。

```shell
gemc b2.yaml -n=1000
```

绘制每次命中的总沉积能量：

```shell
gemc-analyzer b2_t0_digitized.csv totEdep --kind csv
```

![b2 每次命中的总沉积能量][b2-analyzer_totEdep]{:width="70%"}

[b2-analyzer_totEdep]: /home/assets/images/examples/b2/analyzer_totEdep.png

绘制粒子径迹的真值能量：

```shell
gemc-analyzer b2_t0_true_info.csv E --kind csv --data true_info
```

![b2 粒子径迹的真值能量][b2-analyzer_true_energy]{:width="70%"}

[b2-analyzer_true_energy]: /home/assets/images/examples/b2/analyzer_true_energy.png

绘制质子极角残差：

`b2.yaml` 中的 `save_original_track: true` 选项会在真值信息输出中保存 %%otid%% 以及原始动量分量 %%opx%%、
%%opy%% 和 %%opz%%。分析器使用原始动量方向和当前动量方向
来计算 %%delta_theta%%。

```shell
gemc-analyzer b2_t0_true_info.csv delta_theta --kind csv --data true_info --pid 2212 --bins 100 --xlim -0.02 \
  0.2 --linear-y
```

![b2 质子极角残差][b2-analyzer_delta_theta]{:width="70%"}
