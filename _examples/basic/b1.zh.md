## 快速上手

将示例复制到当前目录。
要创建几何结构、运行 10 个事件并生成 ROOT 和 CSV 输出文件：

```shell
cp -r $GEMC_HOME/examples/basic/b1 .
cd b1
./b1.py
gemc b1.yaml -n=10
```

## 几何结构
几何结构如下所示，定义在 `b1.py` 中。 

世界体（一个名为 %%root%% 的长方体）包含： 

- %%Envelope%%，另一个由水构成的长方体。
- %%Shape1%% 和 %%Shape2%%，分别为多圆锥体和梯形体，放置在 %%Envelope%% 内部。它们分别由组织
  和骨材料构成，这些材料常用于医学应用，因此已在
  [Geant4 材料数据库](https://geant4.web.cern.ch/documentation/dev/bfad_html/ForApplicationDevelopers/Appendix/materialNames.html#) 中预先定义：

  - G4_A-150_TISSUE
  - G4_BONE_COMPACT_ICRU

## 数字化

%%Shape2%% 体的灵敏性通过 %%dosimeter%% 数字化处理（GEMC 提供的预置例程之一）
在 `b1.py` 中指定：

```python
gvolume.digitization = 'dosimeter'
gvolume.set_identifier('mydosimeter', 1)
```

%%dosimeter%% 数字化处理在一次运行的各个事件中创建并累积变量 %%etot%% 和 %%dose%%。

$$
\mathrm{dose} = \frac{\mathrm{etot}}{\mathrm{mass}}
$$

其中 %%etot%% 是每个事件中沉积的总能量，%%mass%% 是 %%Shape2%% 的质量。

在此，自定义字符串 %%mydosimeter%% 和数字 %%1%% 用于标识该灵敏元件。

变量 %%mydosimeter%%、%%etot%% 和 %%dose%% 保存在输出中。

更多信息请参阅[剂量计文档]( /home/documentation/sensitivity/dosimeter )。

## 用法

### 构建探测器

使用 Python 脚本 `b1.py` 构建探测器。默认情况下，探测器配置存储在 SQLite 文件
`gemc.db` 中。命令行选项可用于指定数据库类型、变体和运行编号。

{% include notes/python-api-note.md %}

更多信息另见[构建几何结构]( /home/documentation/geometry/geometry_building )。


<br/>

### 运行 GEMC

可以使用文件 `b1.yaml` 来运行该配置。
添加 `-gui` 以交互方式运行 GEMC：

```shell
gemc b1.yaml -gui
```

场景注释和装饰存放在 `annotations.yaml` 中，这样同一个示例既可以带标签渲染，也可以不带标签渲染：

```shell
gemc b1.yaml
gemc b1.yaml annotations.yaml
```

根据需要修改 `b1.yaml` 或命令行，尤其是添加粒子、控制线程数或更改输出。

## 使用 GEMC Analyzer 绘图

首先运行 GEMC，模拟 20 个事件。默认 YAML 文件会写入供分析器使用的 CSV 数据流。

```shell
gemc b1.yaml -n=20
```

绘制累积剂量：

```shell
gemc-analyzer b1_digitized.csv dose --kind csv
```
