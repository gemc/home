## Démarrage rapide

Copiez l'exemple dans votre répertoire courant.
Pour créer la géométrie, exécuter 10 événements et produire des fichiers de sortie ROOT et CSV :

```shell
cp -r $GEMC_HOME/examples/basic/b1 .
cd b1
./b1.py
gemc b1.yaml -n=10
```

<br/>

## Géométrie
La géométrie, illustrée ci-dessous, est définie dans `b1.py`.

Le monde (une boîte nommée %%root%%) contient :

- %%Envelope%%, une autre boîte constituée d'eau.
- %%Shape1%% et %%Shape2%%, un polycône et un trapézoïde, placés à l'intérieur d'%%Envelope%%. Ils sont constitués de
  matériaux représentant les tissus et les os, courants dans les applications médicales et donc prédéfinis dans la
  [base de données des matériaux de Geant4](https://geant4.web.cern.ch/documentation/dev/bfad_html/ForApplicationDevelopers/Appendix/materialNames.html#) :

  - G4_A-150_TISSUE
  - G4_BONE_COMPACT_ICRU

## Numérisation

La sensibilité du volume %%Shape2%% est spécifiée avec la numérisation %%dosimeter%% (l'une des routines
GEMC prédéfinies disponibles) dans `b1.py` :

```python
gvolume.digitization = 'dosimeter'
gvolume.set_identifier('mydosimeter', 1)
```

La numérisation %%dosimeter%% crée et accumule les variables %%etot%% et %%dose%%
au fil des événements d'une exécution.

$$
\mathrm{dose} = \frac{\mathrm{etot}}{\mathrm{mass}}
$$

où %%etot%% est l'énergie totale déposée à chaque événement et %%mass%% est la masse de %%Shape2%%.

Ici, la chaîne personnalisée %%mydosimeter%% et le nombre %%1%% identifient l'élément sensible.

Les variables %%mydosimeter%%, %%etot%% et %%dose%% sont enregistrées dans la sortie.

Voir la [documentation du dosimètre]( /home/documentation/sensitivity/dosimeter ) pour plus d'informations.

## Utilisation

### Construction du détecteur

Utilisez le script Python `b1.py` pour construire le détecteur. Par défaut, la configuration est stockée
dans un fichier SQLite nommé `gemc.db`. Des options en ligne de commande permettent de définir le type
de base de données, les variations et le numéro d'exécution.

{% include notes/python-api-note.md %}

Voir aussi la [construction de la géométrie]( /home/documentation/geometry/geometry_building )
pour plus d'informations.


<br/>

### Exécution de GEMC

Le fichier `b1.yaml` permet d'exécuter la simulation avec cette configuration.
Ajoutez `-gui` pour exécuter GEMC de manière interactive :

```shell
gemc b1.yaml -gui
```

Les annotations et décorations de la scène se trouvent dans `annotations.yaml` afin que le même exemple
puisse être rendu avec ou sans étiquettes :

```shell
gemc b1.yaml
gemc b1.yaml annotations.yaml
```

Modifiez `b1.yaml` ou la ligne de commande selon vos besoins, en particulier pour ajouter des particules,
contrôler le nombre de threads ou changer la sortie.

## Sortie

L'option %%gstreamer%% sélectionne le nom et le format de la sortie. Le fichier YAML écrit simultanément
des flux CSV et ROOT :

```yaml
gstreamer:
  - format: csv
    filename: b1
```

{% include notes/output-note.md %}

Voir aussi la [documentation sur la sortie]( /home/documentation/output ) pour plus d'informations.

<br/>

## Tracé avec l'analyseur GEMC

Exécutez d'abord GEMC avec 20 événements. Le fichier YAML par défaut écrit les flux CSV de l'analyseur.

```shell
gemc b1.yaml -n=20
```

Tracez la dose accumulée :

```shell
gemc-analyzer b1_digitized.csv dose --kind csv
```
