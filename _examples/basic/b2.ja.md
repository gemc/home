## クイックスタート

この例を現在のディレクトリにコピーします。
ジオメトリを作成し、10 イベントを実行して、ROOT と CSV の出力ファイルを生成するには、次のようにします:

```shell
cp -r $GEMC_HOME/examples/basic/b2 .
cd b2
./b2.py
gemc b2.yaml -n=10
```

<br/>

## ジオメトリ

下図に示すジオメトリは `b2.py` で定義されています。

ワールド（%%root%% という名前のボックス）には、次のものが含まれます:

- %%target%%: 鉛（%%G4_Pb%%）からなる円筒形ターゲット
- %%tracker%%: 空気（%%G4_AIR%%）からなる円筒形コンテナ
- %%chamber_0%% から %%chamber_4%% までの名前を持つ 5 つの円筒形チェンバーボリューム。キセノン（%%G4_Xe%%）からなり、横方向のサイズが順に大きくなるように %%tracker%% 内に配置されています

## ジェネレータ

粒子の運動学的条件は YAML ファイルで定義されます:

```yaml
gparticle:
  - name: proton
    p: 3000*MeV
    vz: -250*cm
```

詳細は [内部ジェネレータのドキュメント]( /home/documentation/generator/internal ) も参照してください。

## デジタイゼーション

チェンバーボリュームの感度設定は、%%flux%% デジタイゼーション（GEMC にあらかじめ組み込まれたルーチンの 1 つ）を用いて
`b2.py` 内で指定します。コピー番号が各チェンバーを識別します:

```python
gvolume.digitization = 'flux'
gvolume.set_identifier('mychamber', copyNo)
```

この場合、%%identifier%% には %%mychamber%% という 1 つの名前のみが含まれます。

詳細は [Flux のドキュメント]( /home/documentation/sensitivity/flux ) を参照してください。

デジタイズされた変数に加えて、真値情報も出力ストリームに保存されます。

## 使い方

### ディテクタの構築

ディテクタを構築するには Python スクリプト `b2.py` を使用します。デフォルトでは、セットアップは
`gemc.db` という名前の SQLite ファイルに保存されます。コマンドラインオプションでデータベースの種類、バリエーション、ラン番号を指定できます。

詳細は [ジオメトリの構築]( /home/documentation/geometry/geometry_building ) も参照してください。

<br/>

### GEMC の実行

セットアップを実行するには `b2.yaml` ファイルを使用できます。インタラクティブに実行するには `-gui` を追加します:

```shell
gemc b2.yaml -gui
```

必要に応じて `b2.yaml` を変更します。特に、粒子を追加したり、スレッド数を制御したり、出力を変更したりできます。

## 出力

%%gstreamer%% オプションで出力ファイル名とフォーマットを選択します:

```yaml
gstreamer:
  - format: csv
    filename: b2
```

%%flux%% はイベントごとのデジタイゼーションであるため、GEMC はスレッドごとに 1 つの出力ファイルを生成します。
ROOT ファイルの場合は、`hadd` を使用してファイルをマージできます。

詳細は [出力のドキュメント]( /home/documentation/output ) も参照してください。


<br/>

## GEMC Analyzer によるプロット

まず 1,000 イベントで GEMC を実行します。デフォルトの YAML ファイルは解析ツール用の CSV ストリームを書き出します。

```shell
gemc b2.yaml -n=1000
```

ヒットごとに付与された全エネルギーをプロットします:

```shell
gemc-analyzer b2_t0_digitized.csv totEdep --kind csv
```

![b2 のヒットごとに付与された全エネルギー][b2-analyzer_totEdep]{:width="70%"}

[b2-analyzer_totEdep]: /home/assets/images/examples/b2/analyzer_totEdep.png

粒子トラックの真のエネルギーをプロットします:

```shell
gemc-analyzer b2_t0_true_info.csv E --kind csv --data true_info
```

![b2 の粒子トラックの真のエネルギー][b2-analyzer_true_energy]{:width="70%"}

[b2-analyzer_true_energy]: /home/assets/images/examples/b2/analyzer_true_energy.png

陽子の極角残差をプロットします:

`b2.yaml` 内の `save_original_track: true` オプションは、真値情報の出力に %%otid%% と元の運動量成分 %%opx%%、
%%opy%%、%%opz%% を保存します。解析ツールは元の運動量方向と現在の運動量方向を用いて
%%delta_theta%% を計算します。

```shell
gemc-analyzer b2_t0_true_info.csv delta_theta --kind csv --data true_info --pid 2212 --bins 100 --xlim -0.02 \
  0.2 --linear-y
```

![b2 の陽子の極角残差][b2-analyzer_delta_theta]{:width="70%"}
