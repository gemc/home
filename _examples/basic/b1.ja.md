# サンプル b1
<hr style="height:4px;border:0;background:#4a90e2;">

<br/>

このサンプルは [Geant4 の基本サンプル B1][example] を再現したものです。%%dosimeter%% のデジタイゼーションを
使用して、検出器の累積線量を記録します。

## クイックスタート

サンプルをカレントディレクトリにコピーします。
ジオメトリを作成し、10 イベントを実行して、ROOT と CSV の出力ファイルを生成するには、次のようにします:

```shell
cp -r $GEMC_HOME/examples/basic/b1 .
cd b1
./b1.py
gemc b1.yaml -n=10
```

<br/>

## ジオメトリ
以下に示すジオメトリは `b1.py` で定義されています。 

ワールド（%%root%% という名前のボックス）には、次のものが含まれます: 

- %%Envelope%%。水でできたもう 1 つのボックスです。
- %%Shape1%% と %%Shape2%%。%%Envelope%% の内部に配置されたポリコーンと台形体です。これらはそれぞれ組織と
  骨の材料でできており、医療用途でよく使われるため、
  [Geant4 材料データベース](https://geant4.web.cern.ch/documentation/dev/bfad_html/ForApplicationDevelopers/Appendix/materialNames.html#) にあらかじめ定義されています:

  - G4_A-150_TISSUE
  - G4_BONE_COMPACT_ICRU

## デジタイゼーション

%%Shape2%% ボリュームの感応設定は、%%dosimeter%% のデジタイゼーション（GEMC にあらかじめ用意されたルーチンの 1 つ）を使って
`b1.py` 内で指定されています:

```python
gvolume.digitization = 'dosimeter'
gvolume.set_identifier('mydosimeter', 1)
```

%%dosimeter%% のデジタイゼーションは、ラン内の各イベントを通じて変数 %%etot%% と %%dose%% を生成し、累積します。

$$
\mathrm{dose} = \frac{\mathrm{etot}}{\mathrm{mass}}
$$

ここで、%%etot%% は各イベントで付与された総エネルギー、%%mass%% は %%Shape2%% の質量です。

ここでは、ユーザー指定の文字列 %%mydosimeter%% と数値 %%1%% が感応素子を識別します。

変数 %%mydosimeter%%、%%etot%%、%%dose%% が出力に保存されます。

詳細については [線量計のドキュメント]( /home/documentation/sensitivity/dosimeter ) を参照してください。

## 使い方

### 検出器の構築

Python スクリプト `b1.py` を使って検出器を構築します。デフォルトでは、セットアップは `gemc.db` という名前の SQLite ファイルに
保存されます。コマンドラインオプションで、データベースの種類、バリエーション、ラン番号を指定できます。

{% include notes/python-api-note.md %}

詳細については [ジオメトリの構築]( /home/documentation/geometry/geometry_building ) も参照してください。


<br/>

### GEMC の実行

`b1.yaml` ファイルを使ってセットアップを実行できます。
GEMC をインタラクティブに実行するには `-gui` を追加します:

```shell
gemc b1.yaml -gui
```

シーンの注釈や装飾は `annotations.yaml` に記述されており、同じサンプルをラベル付き・ラベルなしのどちらでもレンダリングできます:

```shell
gemc b1.yaml
gemc b1.yaml annotations.yaml
```

必要に応じて `b1.yaml` やコマンドラインを変更してください。特に、粒子の追加、スレッド数の制御、出力の変更などを行えます。

## 出力

%%gstreamer%% オプションで出力の名前と形式を選択します。この YAML ファイルは CSV と ROOT のストリームを同時に書き出します:

```yaml
gstreamer:
  - format: csv
    filename: b1
```

## GEMC Analyzer によるプロット

まず 20 イベントで GEMC を実行します。デフォルトの YAML ファイルがアナライザ用の CSV ストリームを書き出します。

```shell
gemc b1.yaml -n=20
```

累積線量をプロットします:

```shell
gemc-analyzer b1_digitized.csv dose --kind csv
```
